# talon

My personal [Talon Voice](https://talonvoice.com) commands and settings,
layered on top of [talonhub/community](https://github.com/talonhub/community).

## Install

Clone this repo into your Talon user folder as `personal`:

```sh
git clone https://github.com/theTrueJedi/talon.git ~/.talon/user/personal
```

`community` (and any other add-ons) are installed separately beside it.
Nothing machine-specific or proprietary belongs here.

## Contents

- `settings.talon`: overrides of community settings (macOS).
- `soft_newline.talon`: `soft line` / `soft paragraph` in command, dictation, and mixed mode
  (Shift+Return, for chat apps where Return sends).
- `cheatsheets/`: printable references (HTML source + PDF). Print at 100%.
  - `talon-cheat-sheet`: two-page basics for talonhub/community.
  - `talon-alphabet-card`: cut-out alphabet card, 3-row and 4-row versions.
